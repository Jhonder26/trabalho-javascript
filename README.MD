# Trabalho de JavaScript - SENAI

**Nome do aluno:** Yonder Mendoza

**Nome da atividade:** Atividade Prática de JavaScript (JS) - Cálculos de Médias

## Descrição dos exercícios
1. **Exercício 1 (Média de Aluno):** Calcula a média aritmética de 4 notas de um aluno.
2. **Exercício 2 (Média de Vendas):** Calcula a média semanal de vendas de um vendedor com base em 4 semanas.
3. **Exercício 3 (Consumo de Energia):** Calcula a média de consumo elétrico mensal e verifica se está dentro da meta de 150 kWh.

## Tecnologias utilizadas
* JavaScript (Node.js)
* Git e GitHub
* VS Code

## Orientações para executar os programas
1. Abra o terminal na pasta do projeto.
2. Certifique-se de ter o Node.js instalado.
3. Para executar qualquer exercício, utilize o comando:
   `node nome_do_arquivo.js` (ex: `node Exercicio1.js`)
